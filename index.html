    Notation conventions & tips

    Swar (Roman shorthand): S R G m P D N shuddha; lowercase r g d n komal; M teevra Ma. Devanagari mode inserts komal with a low line (रे॒) and teevra with a vertical stroke (म॑). Saptak: click a note, then Mandra (dot below) or Taar (dot above) to mark the octave of the last note in the cell.

    Several notes in one matra: just type them together, e.g. GR or SRGm. Use - to hold a note, ऽ to extend a syllable, ( ) to group kan or meend.

    Starting mid-cycle: many bandishes start before sam (e.g. the mukhda at matra 12 or 13 in Teentaal). Set Line starts at in the toolbar so each line begins on that matra (e.g. 12 13 14 15 16 | ✕ 1 2 3 4 | … | 9 10 11), keeping the whole phrase on one line. Each avartan can override it with its own Start picker. Notation stays tied to the real matra numbers, so changing the start never moves what you've written.

    Keys: Tab runs along the row: across the Swar line, then the Bol line of the same avartan, then the next avartan (Shift+Tab goes back). Enter moves to the next matra in the same kind of row (Swar→Swar or Bol→Bol) across avartans; Shift+Enter goes back. Ctrl+S saves. Use the section tag on each avartan (Sthayi, Antara, …) to group lines.

    Saving: everything autosaves in this browser. Link save folder (Chrome / Edge) writes each bandish as a .bandish.json file into a folder you choose, e.g. a Bandish_Data subfolder next to this file. Export / Backup all work in every browser.

    Theka bols are the common versions; they vary by gharana, so use Edit theka to match your teacher's. Changes apply to this bandish only.
